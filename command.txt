Список команд бота и описание (command.txt)

Общие команды (доступны всем):

/start
  - Описание: Приветственное сообщение и клавиатура с категориями.

/all
  - Описание: Показать все категории и количество гайдов в каждой.

/guide <тема>
  - Описание: Поиск гайда по теме с использованием fuzzy search (fuzzywuzzy).
  - Пример: /guide battery

/гайд <тема>
  - То же, что и /guide (русский алиас).

/recommend
  - Описание: Показать рекомендованные репозитории автора (Dimasick-git).
  - Что делает: делает запрос к GitHub API для получения списка публичных репозиториев и возвращает ссылки.


Админские команды (требуется быть в ADMIN_IDS):

/sync
  - Описание: Принудительная синхронизация источников (YouTube и GitHub). Обновляет категорию "YouTube - Видео" и "📦 Прошивка и CFW".

/purge_autoguides
  - Описание: Перемещает всю категорию "🆕 Авто-гайды" в "Архив - Авто-гайды" и удаляет её из основных категорий.

/toggle_autoresolve
  - Описание: Переключает режим авто-обработки авто-дайдов.
  - Значение: SETTINGS['auto_resolve_and_add'] = True/False.
    - True: при успешном разрешении DuckDuckGo ссылка будет добавлена в категорию "🔎 Авто-найденные" и удалена из "🆕 Авто-гайды".
    - False: при разрешении прямая ссылка заменит существующую запись в "🆕 Авто-гайды" (legacy поведение).

/cleanup_duplicates
  - Описание: Удаляет повторяющиеся ссылки в `guides.json` (оставляет только первое вхождение каждой уникальной ссылки).
  - Что делает: удаляет повторяющиеся ссылки по нормализованному URL (игнорируются query/fragment).

/admin_help
  - Описание: Показывает список доступных админских команд.

Примечания по настройке и файлам:

- Файл `bot_settings.json` содержит настройки рантайма (например, auto_resolve_and_add). Он создаётся и обновляется автоматически.
- Файл `guides.json` — основная база гайдов. После выполнения очистки дубликатов некоторые записи могут быть удалены.
- Чтобы добавить/убрать администраторов, установите переменную окружения ADMIN_IDS со списком id (через запятую) или измените вручную в коде (не рекомендуется).

Если нужно расширить список команд или изменить поведение (например, показывать репозитории не через GitHub API, а статически), напишите — внесу изменения.
