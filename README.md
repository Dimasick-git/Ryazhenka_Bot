# 🎮 Ryazhenka Helper Bot

**Ryazhenka Helper** — это Telegram-бот, созданный для безопасной, структурированной поддержки моддинга Nintendo Switch.  
Он помогает новичкам и опытным пользователям находить проверенные гайды, архивы и инструкции без риска и путаницы.
