# 🎮 Ryazhenka Helper Bot

Ryazhenka Helper — это удобный и аккуратный Telegram‑бот для поиска и синхронизации гайдов по моддингу Nintendo Switch. Он помогает собирать, структурировать и делиться проверенными инструкциями из YouTube и GitHub.

Ключевые возможности
- Интеллектуальный fuzzy-поиск по базе гайдов (fuzzywuzzy)
- Автоматическая синхронизация из YouTube (RSS) и GitHub (releases.atom)
- Фоновый резолвер DuckDuckGo → прямые ссылки (allowed domains)
- Автоматическое добавление или перемещение найденных ссылок в отдельную категорию
- Админ‑инструменты для очистки, модерации и управления (sync, purge, cleanup)
- Лёгкий деплой на Railway с health endpoint

## � Быстрый старт (локально)

1. Клонируйте репозиторий и перейдите в каталог проекта.
2. Создайте и активируйте виртуальное окружение (рекомендуется):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

3. Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

4. Скопируйте `.env.example` в `.env` и заполните переменные (BOT_TOKEN обязательно).

5. Запустите бота:

```powershell
python .\main.py
```

Ожидаемые логи при успешном старте:
- "🤖 Бот запущен и готов к работе!"
- "📚 Загружено X категорий"

## 📋 Команды

Все команды подробно описаны в `command.txt`. Кратко:

Общие команды (всем):
- `/start` — приветствие и клавиатура категорий
- `/all` — список всех категорий и количество гайдов
- `/guide <тема>` — fuzzy-поиск по базе
- `/гайд <тема>` — русскоязычный алиас для `/guide`
- `/recommend` — рекомендуемые репозитории автора (`Dimasick-git`)

Админские команды (только для `ADMIN_IDS`):
- `/sync` — принудительная синхронизация (YouTube + GitHub)
- `/purge_autoguides` — переместить `🆕 Авто-гайды` в `Архив - Авто-гайды`
- `/toggle_autoresolve` — переключить режим auto-resolve-and-add (сохраняется в `bot_settings.json`)
- `/cleanup_duplicates` — удалить повторяющиеся ссылки в `guides.json`
- `/admin_help` — список админских команд

## Как работает авто-резолв и "resolve-first" поведение

- Новые автогайды сначала попадают в `🆕 Авто-гайды` как поиск (DuckDuckGo).
- Фоновый резолвер пытается найти прямую ссылку на разрешённые домены (см. ALLOWED_DOMAINS в коде).
- По умолчанию (`auto_resolve_and_add = True`) найденные ссылки перемещаются в `🔎 Авто-найденные` и удаляются из `🆕 Авто-гайды`.
- Если `auto_resolve_and_add = False`, разрешённая ссылка заменит запись в `🆕 Авто-гайды` (legacy).
- Админ может переключать поведение командой `/toggle_autoresolve`.

## Файлы проекта и структура данных

- `main.py` — основной код бота (хендлеры, резолверы, фоновые задачи)
- `guides.json` — хранилище категорий и гайдов (категория -> {title: url})
- `bot_settings.json` — сохранённые настройки (например, `auto_resolve_and_add`)
- `command.txt` — описание всех команд (человекочитаемый справочник)
- `resolve_links.py` — вспомогательный скрипт для оффлайн-резолвинга ссылок
- `check_bot_token.py` — быстрая проверка BOT_TOKEN для локальной диагностики

## 🔧 Переменные окружения (важно для Railway и локального `.env`)

- `BOT_TOKEN` — токен от @BotFather (обязательно)
- `YT_CHANNELS` — comma-separated (channel_id или URL/handle)
- `GITHUB_REPO` — репозиторий для releases (пример: `Dimasick-git/Ryzhenka`)
- `ADMIN_IDS` — comma-separated Telegram IDs для админов
- `SYNC_INTERVAL_SECONDS` — интервал фоновой синхронизации (по умолчанию 3600)
- `LOG_LEVEL` — INFO / DEBUG
- `GITHUB_TOKEN` — (опционально) GitHub personal token для увеличения лимитов API

## 📦 Деплой на Railway (коротко и по делу)

1. Запушьте репозиторий на GitHub.
2. Создайте проект в Railway и настройте Deploy from GitHub.
3. В Project Settings → Variables добавьте нужные env vars (см. выше).
4. `Procfile` уже содержит `worker: python main.py`. Если хотите, используйте `web: python main.py` — бот запустит health endpoint `/health`.
5. Нажмите Deploy и проверьте логи.

Совет: если вы видите ошибки rate limit при вызовах GitHub — добавьте `GITHUB_TOKEN`.

## Безопасность и эксплуатация

- Никогда не коммитьте `BOT_TOKEN` в публичные репозитории.
- Для стабильной работы резолвера не добавляйте тысячи автогаидов сразу — это потребляет внешние API и трафик.
- При большой нагрузке используйте `GITHUB_TOKEN`, уменьшите частоту `SYNC_INTERVAL_SECONDS` и включите `LOG_LEVEL=DEBUG` для логов.
